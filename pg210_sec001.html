EXPLORANDO O JOGO

Para os estudantes que ti-
verem mais facilidade, pro-
ponha que joguem com três
dados para chegar a um nú-
mero maior, por exemplo, o
300; já para os que tiverem
mais dificuldade, proponha
que comecem jogando com
apenas um dado e, à medida
que forem se familiarizando,
aumente o desafio. Esse é um
momento também de avalia-
ção diagnóstica, pois se pre-
tende analisar os conheci-
mentos que os estudantes já
têm sobre o sistema de nu-
meração decimal até aqui.
Observe se já leem números
de 3 algarismos, se já identi-
ficam o valor posicional de
um número etc.
