Oriente os estudantes para que observem as imagens e solicite que identifiquem na legenda onde está escrito o nome desse alimento.

Aproveite o momento para observar como eles estabelecem essa relação entre a imagem e a palavra que a representa.

Chame a atenção dos estudantes para a altura do açaizeiro (25 metros), perguntando se já viram uma palmeira desse tipo pessoalmente ou se conhecem alguma outra árvore que seja tão alta quanto os açaizeiros.

Estimule os estudantes a estimar a altura das árvores que conhecem.
